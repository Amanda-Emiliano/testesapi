## 💡 Desafio
Desenvolvimento de um sistema de Comunicação Aumentativa e Alternativa (CAA/AAC), utilizando modelos de embeddings para auxiliar na identificação e associação de conteúdos. O projeto envolve a definição dos requisitos funcionais e não funcionais, análise dos principais trade-offs da solução e implementação do sistema em Java.

### ❓ Como executar, usar e testar o produto

Para executar o programa, siga os passos abaixo:

1.  Certifique-se de ter o **IntelliJ** instalado em seu computador.
2.  Utilize o seguinte código para usar o Sistema de AAC [Clique aqui!](https://github.com/larijuno/Grupo_JAVA/blob/7ab74b9f2713163626e2468b0f1db64de588703c/Ollama%20/Main)
3.  Abra o arquivo no IntelliJ.
4.  Pressione a tecla **Shift + F10** do seu teclado ou clique no ícone de "▶️" no IntelliJ, para iniciar o programa.
5.  Siga as instruções apresentadas no manual de uso do Sistema.
